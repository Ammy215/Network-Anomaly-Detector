# Security Policy

NetSentinel is a personal learning/portfolio project, currently in early foundation-phase development. It has no production deployment or real users yet.

## Reporting a Vulnerability

If you find a security issue, please open a [GitHub Issue](https://github.com/Ammy215/Network-Anomaly-Detector/issues) describing:

- What you found and where (file/endpoint)
- Steps to reproduce
- Potential impact

This project has no bug bounty and no formal SLA, but reports will be looked at and addressed as soon as reasonably possible.

## Scope

- This tool is built for use against your own machines, your own lab, or explicitly authorized networks only.
- No stealth traffic interception, credential-theft, or malware-generation features exist or will be added.
- Uploaded files (PCAPs) are never executed — only parsed defensively.

## Supported Versions

Pre-release / foundation phase — there are no versioned releases yet. Only `main` is maintained.
